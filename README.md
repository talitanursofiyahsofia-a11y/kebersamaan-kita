# kebersamaan-kita

Sebuah portfolio interaktif yang dapat di‑host di GitHub Pages (frontend) atau di‑deploy ke platform backend (Node.js) untuk menyimpan media di Google Drive.

## ✨ Fitur

- Upload foto/video/audio ke Google Drive (via OAuth2).
- Teks kenangan yang bisa diedit.
- Background (gambar/video) yang dapat di‑ganti.
- Link publik untuk melihat/menyunting.
